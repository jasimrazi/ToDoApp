# To-Do App

This is a simple and efficient **To-Do Application** built using **Flutter** for managing tasks with offline accessibility. The app allows users to add, edit, and delete tasks while ensuring a clean and user-friendly experience.

---

## Features

### 🌟 General Features
- **Task Management**
  - Add, edit, and delete tasks with ease.
  - Organize daily tasks for better productivity.

- **Offline Support**
  - Tasks are stored locally using **SQFlite**, ensuring accessibility even without an internet connection.

- **User-Friendly Interface**
  - Clean and intuitive design for quick navigation.
  - Interactive task cards for a seamless user experience.

### 📂 Additional Features
- **State Management**
  - Efficient task handling with **Provider** for state management.
  - Dynamic UI updates for task creation, modification, and deletion.

- **Local Storage**
  - Persistent storage for tasks using **SQFlite**, enabling data retention across app restarts.

---

## Tech Stack

### 🖥️ Frontend
- **Flutter**
  - State management with **Provider**.
  - Material Design components for a modern and responsive UI.

### 📂 Database
- **SQFlite**
  - Local SQLite database for offline task storage and management.
